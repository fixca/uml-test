# 강승현 담당 프론트엔드 구현 정책

## 적용 범위

`10-frontend.md`의 F6~F12와 `00-common.md` 5장의 공개 API를 구현 기준으로
사용한다. 최신 제품 설계의 클래스/시퀀스 확장, Mermaid JS, 비동기 자동 복구,
객체 삭제는 이번 주 담당 업무와 현재 공개 API 밖이므로 여기서 추가하지 않는다.
시퀀스 렌더러나 자동 복구가 구현되었다고 간주하지 않는다.

## 기본값

| 항목 | 채택한 값과 이유 |
|---|---|
| 창과 분할 | 1200×800, 코드:캔버스 1:2, 사용자가 경계 이동 가능 |
| 자동 검증 | 마지막 원문 입력 후 200ms, 공통 F8 기준 |
| 오류 | 원문 유지, 모든 오류 줄 강조, 상태줄에는 첫 오류 표시 |
| 오류 중 그림 | 마지막 정상 장면 유지, 이동·관계 변경·붙여넣기 거부 |
| 이력 | 코드와 layout 깊은 복사, 최대 100회 Undo, 200ms 입력 묶음 |
| 저장 상태 | 저장된 스냅샷과 현재 내용 비교, Undo로 저장본에 도달하면 ● 제거 |
| 저장 대화상자 | `.umlproj` 기본 확장자, 덮어쓰기는 Qt 확인 절차 사용 |
| 미저장 전환 | 저장/저장 안 함/취소, 기본 저장, Esc는 취소 |
| 최근 파일 실패 | 실패 안내 후 예시가 있는 새 문서, 기존 파일 보존 |
| 내보내기 | SVG 기본, PNG/JPEG 1·2·4배, SVG는 1배 고정 |
| 오류 중 내보내기 | 비활성화, 이전 정상본 별도 출력 흐름은 후속 범위 |
| 내보내기 선택 | 선택을 일시 해제하고 성공·실패 모두 기존 선택 복원 |
| 복사 | 클래스 하나의 선언을 일반 텍스트 클립보드에 저장 |
| 붙여넣기 | 단일 명시적 클래스만 허용, 충돌하면 User2, User3 순서 |
| 붙여넣기 좌표 | 복사 위치에서 오른쪽·아래 24px, 반복할 때 누적 |
| 외부 텍스트 위치 | 현재 화면 중심에서 오른쪽·아래 24px |
| 확대/축소 | 1.2배 단계, 화면 맞춤 제공, 문서 이력과 분리 |

## 팩토리 통합 지점

현재 `factory.build()`와 그림 요소는 미구현이다. 담당 외 파일을 대신 구현하지
않으며, 미구현이면 상태줄에 명시하고 빈 그림의 내보내기를 비활성화한다.
컨트롤러는 공개 `build(scene, diagram, layout)` 서명을 그대로 호출한다.

시그널 이름과 인자는 공통사항 그대로 유지한다. 공통사항에 시그널 객체를
전달하는 위치와 선택 ID 규약은 없으므로 다음 어댑터 기본값을 채택했다.

- 기본 장면 `DiagramScene.signals`에 `DiagramSignals`가 있다.
- 팩토리가 자체 집계 객체를 소유하면 `Controller.bind_signals(signals)`로
  한 번 연결할 수 있다. 같은 객체를 중복 연결하지 않는다.
- 선택한 클래스는 Qt 공개 `QGraphicsItem.data(0)`에 class_id를 둔다.
  관계선은 이 슬롯을 비워 두며, 자식 텍스트는 별도 선택 대상으로 만들지 않는다.
- 자동 배치 좌표를 저장·Undo·복사 위치에 반영하려면 팩토리가 받은
  `layout.nodes`에 초기 위치를 채워야 한다. 수동 좌표는 우선 보존한다.

이는 기존 함수·시그널 서명을 변경하지 않는 연결 기본값이다. 실제 그림 요소
담당자가 다른 공개 선택/시그널 접근 방식을 제공하면 어댑터를 맞춰야 한다.

## 문서와 현재 코드의 차이

최신 제품 설계는 ZIP 저장과 PNG/JPEG 우선을, 1주차 공통 문서는 JSON 저장과
SVG 우선을 기술한다. 프론트엔드는 저장 포맷을 직접 구현하지 않고 현재
`storage.save/load`에 위임하며, 내보내기는 F10의 SVG/PNG/JPEG를 제공한다.
현재 작업 폴더의 백엔드 구현은 ZIP을 사용한다. 저장 인터페이스는 변경하지 않는다.

자동 복구 보관 기간이나 Mermaid JS 버전은 실제 구현이 없는 상태에서 설정된
것으로 기록하지 않는다. 후속 확장 시 제품 설계와 1주차 범위의 우선순위를
총괄이 정리해야 한다.

## 검증 전제

프론트 테스트는 Qt offscreen과 간단한 테스트용 팩토리를 사용한다. 실제 UML
도형·연결선·드래그 시각 품질 검증은 F1~F5 통합 후 필요하다. 로컬의 기존
백엔드 변경은 이 작업의 커밋 대상이 아니므로 해당 구현의 별도 병합이 필요하다.
로컬 내보내기 통합 검사에서 `QGraphicsScene.render`의 키워드 인자가
`aspectRatioMode`가 아닌 `mode`임을 확인해 `umlparser/export.py` 한 줄을
수정했다. 해당 수정도 기존 백엔드 변경과 함께 작업 폴더에 남긴다.
